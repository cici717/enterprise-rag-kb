# 智能客服平台产品介绍

## 产品定位

智能客服平台面向电商、教育和企业服务行业，提供在线客服、智能问答、工单流转和数据统计能力。平台支持网页、微信、企业微信和 API 接入。

## 核心功能

### 智能问答

基于企业知识库进行检索增强生成，回答时附带引用来源。支持多轮对话、敏感词过滤和人工转接。

### 工单管理

客服可以将复杂问题创建为工单，并指定处理人、优先级和截止时间。工单状态包括待处理、处理中、已解决和已关闭。

### 数据分析

平台提供会话量、解决率、平均响应时间、人工转接率和用户满意度等指标。管理员可以按天、周、月查看趋势。

## 部署方式

标准版支持公有云 SaaS 部署。企业版支持私有化部署，提供 Docker Compose 和 Kubernetes 两种方案。

## 常见问题

Q: 是否支持接入自己的大模型？
A: 支持 OpenAI 兼容接口，可以接入 DeepSeek、Qwen、GLM 和本地部署模型。

Q: 知识库数据会不会用于训练模型？
A: 不会。企业数据仅用于检索和生成回答，不会用于训练公共模型。

Q: 是否支持权限控制？
A: 企业版支持按部门、角色和文档标签控制知识库访问权限。
