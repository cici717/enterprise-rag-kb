# 项目架构

## 整体架构

```mermaid
flowchart LR
    U[用户] --> F[Streamlit 前端]
    F -->|HTTP / SSE| A[FastAPI 后端]
    A --> D[文档解析与切分]
    D --> E[Embedding Provider]
    E --> V[向量检索与混合排序]
    A --> L[LLM Provider]
    A --> DB[(SQLite)]
    A --> C[会话与反馈]
    V --> DB
    L --> A
```

## 文档入库流程

```mermaid
sequenceDiagram
    participant User as 用户
    participant API as FastAPI
    participant Parser as 文档解析
    participant Chunker as 切分
    participant Embed as Embedding
    participant DB as SQLite

    User->>API: 上传文档
    API->>Parser: 解析 PDF/Word/TXT/MD
    Parser->>Chunker: 提取文本
    Chunker->>Embed: 生成 Chunk 向量
    Embed->>DB: 保存文档、Chunk、向量、引用信息
    API-->>User: 返回文档 ID 和 Chunk 数量
```

## 问答流程

```mermaid
sequenceDiagram
    participant User as 用户
    participant API as FastAPI
    participant Retriever as 检索器
    participant LLM as 大模型
    participant DB as SQLite

    User->>API: 提交问题
    API->>Retriever: 问题向量化
    Retriever->>DB: 读取 Chunk 向量
    Retriever-->>API: Top-K 相关片段
    API->>LLM: 拼接 Prompt 并请求回答
    LLM-->>API: 流式返回 token
    API-->>User: SSE 返回引用和 token
    API->>DB: 保存会话和消息
```

## 数据模型

```mermaid
erDiagram
    DOCUMENTS ||--o{ CHUNKS : contains
    CONVERSATIONS ||--o{ MESSAGES : contains
    FEEDBACK }o--|| MESSAGES : rates

    DOCUMENTS {
        int id
        string filename
        string content_type
        int size
        string status
        int chunk_count
        datetime created_at
    }

    CHUNKS {
        int id
        int document_id
        int chunk_index
        text content
        int page
        text embedding
        datetime created_at
    }

    CONVERSATIONS {
        int id
        string title
        datetime created_at
    }

    MESSAGES {
        int id
        int conversation_id
        string role
        text content
        text citations
        datetime created_at
    }
```

## 升级路线

1. 将 SQLite 检索替换为 Chroma 或 Milvus。
2. 加入 BGE-M3 Embedding 和 bge-reranker。
3. 增加 Query Rewrite 和多轮对话改写。
4. 增加文档权限、部门隔离和审计日志。
5. 增加评测集、指标看板和链路追踪。
